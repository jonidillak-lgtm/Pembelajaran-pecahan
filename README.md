# Pembelajaran Pecahan Interaktif

Model pembelajaran pecahan untuk ka otha - aplikasi interaktif yang membantu memahami konsep pecahan.

## Deployment ke Vercel

### Cara 1: Via GitHub (Recommended)
1. Masuk ke [vercel.com](https://vercel.com)
2. Click "New Project"
3. Pilih repository `Pembelajaran-pecahan`
4. Vercel akan otomatis mendeteksi konfigurasi
5. Click "Deploy"

### Cara 2: Via Vercel CLI
```bash
npm i -g vercel
vercel
```

## URL Deployment
Setelah deployment selesai, akses aplikasi di:
`https://pembelajaran-pecahan.vercel.app`

## Files
- `pengenalan_pecahan_interaktif (1).html` - Main learning app
- `vercel.json` - Vercel configuration
- `public/index.html` - Landing page redirect
